# Prompt 04 — Premium Design System

Refine Compressly into a polished production interface.

Design principles:
- minimal
- premium
- technical but approachable
- excellent whitespace
- clear hierarchy
- fast-feeling
- mobile-first

Use:
- consistent spacing scale
- typography scale
- semantic colors
- accessible contrast
- consistent border radius
- subtle elevation
- clear interactive states

Avoid:
- excessive gradients
- excessive glassmorphism
- giant decorative illustrations
- random emoji
- generic SaaS blobs
- fake dashboard metrics
- unnecessary animations

Motion should be subtle:
- upload hover
- button feedback
- progress transitions
- card entrance
- completion state

Respect prefers-reduced-motion.

Make mobile feel intentionally designed rather than merely responsive.
