# Prompt 03 — Build the UI

Implement the complete Compressly interface.

Required sections:

## Header
- Compressly logo/wordmark
- Short privacy message
- Theme toggle

## Hero
Headline:
"Compress images without uploading them."

Supporting copy:
"Fast, private, browser-based image compression. Your files stay on your device."

Primary action:
"Choose images"

Secondary:
"Drop files here"

## Upload Zone
Support:
- click
- drag enter
- drag leave
- drop
- keyboard activation

Show accepted formats.

## Configuration Panel
Controls:
- compression preset
- custom quality
- output format where appropriate
- max width
- max height
- preserve aspect ratio
- prevent upscaling

Make advanced settings collapsible on mobile.

## File Queue
Each image card should show:
- thumbnail
- filename
- original dimensions
- original size
- status
- progress
- compressed size
- savings percentage
- remove button
- download button when complete

## Batch Controls
Show:
- total images
- total original size
- total compressed size
- total savings
- Compress All
- Download ZIP
- Clear All

## Empty State
Make the empty state useful and visually strong.

## Completion State
Show a concise success summary and download actions.

## Footer
Include:
- privacy statement
- supported formats
- limitation note
- project/about link placeholder

Do not fabricate company claims, security certifications, customer numbers, or testimonials.
