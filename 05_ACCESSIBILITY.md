# Prompt 05 — Accessibility Pass

Audit and fix the entire application for accessibility.

Check:
- semantic HTML
- keyboard navigation
- visible focus states
- logical tab order
- button labels
- form labels
- aria attributes only where necessary
- screen-reader announcements for compression progress
- drag-and-drop alternative
- color contrast
- error messaging
- reduced motion
- touch target sizes
- disabled states
- loading states

A user must be able to complete the entire workflow without a mouse.
