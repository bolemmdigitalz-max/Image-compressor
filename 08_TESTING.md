# Prompt 08 — Testing and QA

Create a practical test strategy and implement tests where appropriate.

Test:
- file validation
- image result calculations
- savings percentage
- resize calculations
- MIME selection
- filename generation
- queue operations
- duplicate filenames
- batch success
- partial batch failure
- ZIP generation
- reset/clear behavior

Also perform manual browser QA for:
- Chrome
- Firefox
- Safari where available
- mobile viewport
- desktop viewport

Verify:
- no console errors
- no TypeScript errors
- no broken imports
- no obvious memory leaks
- downloads work
- ZIP opens correctly
- UI remains usable during compression
