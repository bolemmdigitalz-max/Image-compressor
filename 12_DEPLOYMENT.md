# Prompt 12 — Production Build and Deployment

Prepare Compressly for deployment as a static frontend.

Verify:
- npm install works
- npm run build works
- npm run preview works
- production assets load correctly
- SPA routing is not broken if routes are added
- no development-only code leaks into production
- no secrets are required
- no backend is required

Optimize the Vite production build where useful.

Before completion, run the production build and fix all blocking errors.
