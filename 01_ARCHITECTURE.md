# Prompt 01 — Architecture and Implementation Plan

Using the Compressly master brief, design the technical architecture before writing the application.

Produce:
1. Component tree
2. State model
3. TypeScript interfaces/types
4. Image-processing pipeline
5. ZIP pipeline
6. Error-handling strategy
7. Browser compatibility strategy
8. Memory-management strategy
9. Accessibility strategy
10. Performance strategy

Then implement the architecture.

Important:
- Do not create a backend.
- Do not upload images.
- Keep processing modules independent from React components.
- Use deterministic, testable functions wherever practical.
- Avoid overengineering.
- Do not introduce a state-management library unless genuinely necessary.
